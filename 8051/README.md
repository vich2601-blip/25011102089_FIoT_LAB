# 8051 Experiments (CAT 2 – CAT 7)

Bare-metal Embedded C on the AT89S52 (11.0592 MHz) with Keil µVision. Each task folder is a complete Keil project (`*.uvproj`, `STARTUP.A51`, sources) with its firmware in `Objects/*.hex`, a README and a circuit diagram.
